Usable Excel — Certification Testing Notes

Product: Usable Excel  |  Version: 1.0.1.3  |  Manifest: https://flowcore-io.github.io/usable-excel/manifest.prod.xml

1. Authentication

The add-in requires a Usable account to function.

  • Accounts are free — sign up at https://usable.dev
  • No credit card or purchase required at any point
  • After signing up, click Sign in in the task pane and complete the OAuth login flow
  • The add-in uses Keycloak PKCE OAuth via the Office Dialog API (standard Office Add-In pattern)

2. Installing the add-in for testing

Option A — Via AppSource (once published):

Open Excel → Insert → Add-ins → search "Usable Excel"

Option B — Sideload the manifest directly:

  1. Download: https://flowcore-io.github.io/usable-excel/manifest.prod.xml
  2. Excel on the web: Insert → Add-ins → Upload My Add-in → paste the URL or upload the file
  3. Excel on Windows/Mac: Insert → Add-ins → My Add-ins → Upload My Add-in

3. Opening the add-in

Once installed:

  1. Go to the Home ribbon tab
  2. Click Usable Chat in the Usable group
  3. The task pane opens and loads the Usable Chat interface
  4. Sign in with a free Usable account if prompted

4. Test scenarios

Scenario What to type in the chat Expected result
Read workbook "What sheets are in this workbook?" AI lists the sheet names
Read cells "What's in cell A1?" AI reads and describes the value
Write to a cell "Write 'Hello World' in cell A1" Cell A1 contains Hello World
Format cells "Make A1 bold and blue" Cell A1 is bold with blue text
Create a sheet "Add a new sheet called Summary" New sheet appears in the workbook
Sort data "Sort column A ascending" Column A sorted A→Z
Apply formula "Put =SUM(A1:A10) in cell B1" Formula applied to B1
Create a chart "Create a bar chart from A1:B5" Chart inserted in the sheet

5. Notes for reviewers

  • The add-in connects to https://chat.usable.dev (declared in AppDomains in the manifest)
  • All AI processing is handled by the Usable service at https://api.usable.dev
  • Authentication is handled by Keycloak at https://auth.flowcore.io
  • The add-in has ReadWriteDocument permissions — required to read and write spreadsheet data
  • No spreadsheet data is stored persistently — data is only processed within the active session
